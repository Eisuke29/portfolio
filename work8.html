McDonald's App Trace

Figma で、マクドナルド公式アプリの30画面と画面遷移を完全再現したプロトタイプ

▶ その場で触る 見どころ ↓ 作品について ↓ GitHub ↗ 作品一覧へ ↗

About 説明

いつも使っているアプリを、見た目だけでなく、さわり心地までそっくり再現することを目指した UI トレースです。

ゼミの Figma 入門課題として、日本マクドナルドの公式アプリを題材に、ホーム・クーポン・リワード・デリバリー・モバイルオーダーの30画面をスマホの実寸で作りました。

画面を並べるだけでなく、画面と画面をつなぐ遷移まで作り込んでいます。下のタブで5つの画面を行き来でき、店舗を選ぶ → メニュー → 商品 → ドリンクを選ぶ → 注文内容の確認まで、実際のアプリと同じ順番でたどれます。

おことわり学習のために公式アプリを再現した、非公式の制作物です。日本マクドナルド株式会社とは関係ありません。ロゴ・商品写真・店舗情報などの権利は、日本マクドナルド株式会社に帰属します。

Play その場で触る

スマホと同じように、押して・スクロールして試せます

  • 端末PC・スマホ
  • 操作クリック・スクロール
  • 画面30

押せる場所が分からないときは、画面のどこかを押してみてください。青く光る部分が、押して操作できる場所です。

  1. まず黄色い × でキャンペーンのお知らせを閉じる
  2. 下のタブで クーポン・リワード・デリバリー・オーダー を行き来する
  3. オーダー → 店舗一覧 → 店舗 → 商品 → ドリンクを選ぶ → レジに進む

Figma で大きく開く ↗

操作の様子（34秒）

Points 見どころ

  1. 30画面を実寸でiPhone と同じ 402×874 の画面に、ホーム・アカウント・ポイント・クーポン・リワード・デリバリー・モバイルオーダー、メニュー9カテゴリ、購入の4画面までを作りました。
  2. 画面遷移をすべてつなぐ下のタブ5つ、店舗一覧 → 店舗 → メニュー → 商品 → 注文確定まで、実際のアプリと同じ道すじでたどれます。メニュー上部のカテゴリも切り替えられます。
  3. 動きの再現起動時にキャンペーンのお知らせが重なって開き、× で閉じる。地図の上に店舗一覧のシートが出る。ドリンクを選ぶと内容が増えて「レジに進む」が押せるようになる。
  4. スクロールホームや注文確認の画面は、画面の中だけがスクロールし、上の見出しと下のタブは固定されたまま。
