ダンス動画の骨格推定

動画から人物と17点の骨格を検出し、動きを可視化するMATLABプログラム

処理結果を見る ↓ GitHub ↗ 処理の流れ ↓ 作品について ↓ 作品一覧へ ↗

About 説明

ダンス動画の人物を見つけ、関節と骨格を重ねて動きを見える形にするプログラムです。

人物の検出にはYOLOv4、17点のキーポイントの検出にはHRNetを使用。2つの学習済みモデルをつなぎ、動画の全フレームを処理してMP4へ書き出します。

既存のモデルをただ使うだけでなく、各関数の役割を確かめながらコードを記述しました。Claudeには関数の説明やデバッグの支援を受けています。

Result 実際の処理結果

映像素材：Antoni Shkraba / Pexels（Pexels License）。一部を切り出し、明度調整・骨格描画・比較編集を行っています。

Process 処理の流れ

  1. 明るさを整える動画を1フレームずつ取り出し、HSV色空間の明度を1.2倍に調整します。
  2. 人物を見つけるYOLOv4で人物領域を検出し、人物のラベルだけを次の処理に渡します。
  3. 骨格を推定する人物領域をHRNetに渡し、顔や手足のキーポイント17点を検出します。
  4. 動画に書き出す関節を黄色、骨格を青色で重ね、入力と同じフレームレートのMP4に保存します。

Findings 結果と課題

掲載した8秒・12fps（96フレーム）の例は、MATLAB R2026aで約7分4秒かけて処理しました。制作時の検証では、激しい動きや前屈みの姿勢では、人物の検出失敗や骨格のずれが見られました。

明度補正による精度改善は、今回の映像では明確に確認できていません。照明条件を変えた比較、軽量モデルやGPUの利用、前後フレームからの補間が今後の改善点です。
